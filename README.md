# Teacher Student Management System

A Spring Boot CRUD application for managing Students and Teachers using REST APIs with a simple HTML, CSS, and JavaScript frontend.

## &#x20;

## 🚀 Features

### 👨‍🏫 Teacher Management

* Add Teacher
* View Teacher By ID
* View All Teachers
* Delete Teacher

### 🎓 Student Management

* Add Student
* View Student By ID
* View All Students
* Delete Student

## 🧰 Technology Stack

### Backend

* Java
* Spring Boot
* Maven

### Frontend

* HTML
* CSS
* JavaScript

### Tools

* VS Code
* Git
* GitHub

## 🏗️ Project Architecture

### Backend Structure

* Controller
* Service
* Repository

### Frontend Structure

* index.html
* style.css
* script.js

## ⚙️ Run Project

### Run Backend

```
mvn spring-boot:run
```

Backend runs on:

```
http://localhost:8080
```

### Open Frontend

```
http://localhost:8080
```

## 📘 API Endpoints

### Student APIs

* POST `/student`
* GET `/student/all`
* GET `/student/{id}`
* DELETE `/student/{id}`

### Teacher APIs

* POST `/teacher/add`
* GET `/teacher/all`
* GET `/teacher/{id}`
* DELETE `/teacher/{id}`

## 📌 Notes

* This project uses in-memory data storage.
* Data will reset after restarting the application.
